# 单题测试说明

工程现在支持把前三问拆成单独固件测试。

三个单题入口分别在：

- `tasks/question1_only.h`
- `tasks/question2_only.h`
- `tasks/question3_only.h`

修改 `app_task_mode.h` 里的 `APP_SINGLE_TEST_TASK_ID`：

| 值 | 行为 |
|---|---|
| `0U` | 原验收模式：等待按键或 UART 命令选择任务 |
| `1U` | 只运行第一问：A -> B，到 B 停车并声光提示 |
| `2U` | 只运行第二问：A -> B -> C -> D -> A |
| `3U` | 只运行第三问：A -> C -> B -> D -> A，1 圈 |

每次修改后重新 Build / Flash 即可。

单题模式上电后会先等待 `APP_SINGLE_TEST_START_DELAY_MS`，默认 1000 ms，方便把小车放到 A 点；之后自动运行对应题目，不再等待按键或串口命令。

需要恢复原来的按键/UART 选择模式时，把 `APP_SINGLE_TEST_TASK_ID` 改回 `0U`。
